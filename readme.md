# Huddle · 离线局域网派对平台

> 一台手机变成游戏服务器，朋友们扫码就能加入——没有互联网也能一起玩。

![Build](https://github.com/520MianXiangDuiXiang520/Huddle/actions/workflows/build-android.yml/badge.svg)

Huddle 是一个面向「没有互联网」场景的局域网多人游戏平台。高铁、飞机、露营、旅行、朋友聚会……只要大家连上同一台手机的热点（或同一 Wi-Fi），就能马上开局。

## 为什么是 Huddle

传统多人游戏要么依赖云端服务器，要么要求每个人都安装同一款 App。Huddle 反其道而行：

- **只有房主需要安装 App**——一个极轻量的应用，只做一件事：把手机变成局域网服务器
- **客人零安装**——连上网络后扫码，系统浏览器直接打开网页就能玩
- **整个游戏完全运行在局域网内**，游戏状态只保存在房主手机上，不经过任何云服务器

## 特色

- **离线可玩**：零公网依赖，热点 / Wi-Fi 即可开局
- **客人零安装**：扫码即入，浏览器即玩，无需下载任何东西
- **五款游戏开箱即用**：五子棋、谁是卧底、你画我猜、狼人杀、斗地主
- **权威状态在房主**：网页客户端不保存任何权威状态，天然防作弊
- **双端房主 App**：Android 与 HarmonyOS NEXT 实现同一套产品与同一套网页前端
- **隐私友好**：不注册、不登录、不上云，结束房间即停止本机服务

## 工作原理

房主 App = **本地 HTTP + WebSocket 服务器** + **内嵌 WebView**；客人 = **系统浏览器**。

```
┌─ 房主手机 ─────────────────────────────────┐
│  Host App                                 │
│  ├─ HTTP Server       托管网页资源 (HTML/JS/CSS)
│  ├─ WebSocket Server  房间与游戏状态同步
│  └─ 内嵌 WebView      房主在 App 内一起玩，
│                       保持前台，服务不易被系统挂起
└────────────────────────────────────────────┘
              ▲ 同一热点 / Wi-Fi
              │ 扫码 http://房主IP:端口
┌─ 客人手机（无需安装）──────────────────────┐
│  系统浏览器 → 大厅 → 入座 → 开局            │
└────────────────────────────────────────────┘
```

| 角色 | 使用方式 |
|------|----------|
| 房主 | Host App（服务器 + WebView） |
| 客人 | 系统浏览器（扫码进入） |

游戏 UI 全部由网页完成，房主 WebView 与客人浏览器共用同一套前端页面；所有权威状态（入座、准备、发牌、回合、结算）均由房主端维护并经 WebSocket 同步。

| 游戏 | 人数 | 玩法 | 配置 |
|------|------|------|------|
| 五子棋 | 2 | 经典双人对弈 | — |
| 谁是卧底 | 3–8 | 发放平民词 / 卧底词，线下讨论后房主揭晓 | 词库、卧底人数、人数范围 |

## 技术栈

| 端 | 技术 |
|------|------|
| Android | Kotlin · Ktor Server（CIO + WebSockets）· ZXing（二维码）· Material Design 3；minSdk 26 / targetSdk 35 |
| HarmonyOS NEXT | ArkTS · @kit.NetworkKit（自实现单端口 HTTP/1.1 + WebSocket 服务器）· API 24 |
| 网页前端 | 原生 HTML / CSS / JS（无框架），两端共用同一套页面 |

## 构建与运行

### Android

要求 Android Studio + JDK 17。

```bash
cd android-host
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

或用 Android Studio 打开 `android-host/` 直接运行。

### HarmonyOS NEXT

要求 DevEco Studio（SDK 6.1.1(24)+）。用 DevEco Studio 打开 `harmony-host/`，配置本地签名后运行。

> 注：`harmony-host/signing/` 为本地签名材料（含私钥），已从版本库排除，请勿提交或外泄。

## 隐私说明

- **纯局域网**：开房与对局不经过任何云端服务器
- **不收集**：无账号体系、无广告追踪、不要求通讯录 / 精确定位等与开房无关的权限
- **本地数据**：主题、词库、缓存仅保存在房主设备，可在「更多 → 存储」中查看并一键清理
- **随时退出**：结束房间即停止本机服务，卸载 App 即清除全部本地数据
